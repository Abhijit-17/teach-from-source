# Source wins over first principles

The skill teaches every concept from first principles, but registered sources set how deep a lesson may go, because the skill's core promise is that every cited claim traces to material the learner chose. When first-principles teaching needs foundations no registered source covers, the skill logs a Gap and recommends 1-3 freely available original Supplementary sources. After the learner approves, the skill fetches and ingests them itself. If it cannot (login, paywall, network, missing tool), the learner downloads them into the workspace instead. Material that still has no source is taught only as visibly marked Outside-the-source.

## Considered Options

- **First principles wins**: always teach down to the foundations and cite only the parts that came from the source. Rejected: learners could no longer tell book claims from model recall, which is the failure the skill exists to prevent.
- **Ask each time**: stop before teaching any foundation the source lacks. Rejected: it would interrupt nearly every lesson.
- **Skill fetches Supplementary sources without asking**: rejected, because it would let the skill change what counts as truth for the course without the learner's say.
